GITHUB PAR APK BANANE KA TAREEQA (ANDROID PHONE)

1. ZIP ko phone mein download karke ZArchiver se extract karein.
2. GitHub par New repository banayein. Naam: Nasir-AI-Scanner
3. Extracted NasirAIScanner folder ke ANDAR ki tamam files/folders repository ke root mein upload karein. ZIP file ko akela upload na karein.
4. Upload mein .github/workflows/android-build.yml bhi shamil hona chahiye.
5. GitHub repository mein Actions tab kholein.
6. "Build Nasir AI Scanner APK" workflow select karein.
7. "Run workflow" dabayein.
8. Build complete hone par run ke neeche Artifacts mein Nasir-AI-Scanner-debug-apk download karein.
9. ZIP artifact extract karke app-debug.apk install karein. Android permission prompt aaye to sirf apni marzi se screen capture allow karein.

AHAM: Yeh sirf APK build workflow hai. Is source prototype mein Quotex ka live chart recognition, real-time price feed, OTC feed, aur UP/DOWN signal engine abhi maujood nahi. Current scanner WAIT dikhata hai. APK ban jana live trading scanner ban jane ke barabar nahi. Pehle demo aur non-financial test ke liye hi use karein.
